# 全站 UI 重设计与受控自定义

日期：2026-10-05
状态：用户已确认设计与受控配置范围，并授权开始实现；实现与验证记录见 `../verification/2026-10-05-ui-redesign.md`。

## 1. 目标与边界

重做前台及全部后台页面的布局、排版、视觉和交互状态，保留现有业务能力、数据和认证机制。同时扩展后端持久化设置，让新设计中的品牌内容与外观能够在后台修改，无需重新部署。

不包含拖拽页面搭建、任意 HTML/CSS/JavaScript 注入、新增统计分析服务、认证机制改造或无关业务重构。原型中的文章、日期、草稿和分类仅用于视觉演示，不代表新增业务能力；实现以现有模型与接口实际支持的状态为准。

## 2. 视觉系统

- 默认主题：暖白纸色背景、深墨正文、松绿强调色、细分隔线、低阴影，避免大量嵌套卡片。
- 标题采用本地宋体/衬线字体栈，正文采用系统无衬线字体；不依赖外部字体服务。
- 前台通过留白、字号与文章序号/日期组织层级；后台使用更紧凑的无衬线排版，同色系但优先可操作性。
- 深色模式是独立调校的墨绿灰背景，不直接反转颜色。
- 统一设计变量与基础组件：按钮、表单、面板、状态标签、确认对话框、通知、分页、空态与加载态。
- 桌面与移动端均适配，交互有键盘焦点，尊重减少动画设置；正文及操作文字满足 WCAG AA 对比度。

## 3. 前台布局

### 全局导航与页脚

导航由品牌区、文章/公告/友链入口、语言切换、主题切换与登录状态组成；移动端折叠。页脚包含站点简介、社交链接、版权和可选备案信息。

### 首页

采用左对齐编辑式头部，展示小字、主标题、副标题及可关闭的作者介绍。下方默认以文章列表呈现：标题、摘要、现有文章元信息及可选封面。支持在后台切换为卡片布局、控制封面显示和每页数量。无封面、长标题和多语言均保持完整布局。保留现有分页与翻译功能，不新增原接口不支持的搜索或分类交互。

### 文章详情

窄版阅读栏、清楚的标题与元信息、舒适的正文行距。代码、表格、公式与图片适配容器，移动端仅在必要的代码/表格区域横向滚动。保留评论、登录提示、翻译及现有文章操作。

### 其他页面

公告采用刊物式列表；友链采用统一名片布局；OAuth 登录采用简洁品牌面板；隐私与条款采用阅读页布局。OAuth 回调保留原流程并统一加载/错误表现。

## 4. 后台布局

后台采用独立工作台外壳，避免与前台导航叠加。桌面左侧分组导航、右侧页面标题与操作区；移动端使用可收起导航。

现有模块全部保留，按以下分组组织：

- 概览：统计概览，仅使用真实接口已有指标，不虚构趋势图。
- 内容：文章、评论、审核队列、公告、友链。
- 站点：外观与内容、登录方式。
- 系统：用户、个人资料、安全、AI 审核、翻译队列。

列表页统一操作位置、加载/空/失败状态与删除确认；设置页统一分区、帮助说明和保存反馈。长配置表单支持折叠分组，敏感信息仍遵守现有隐藏规则。

文章新建与编辑纳入工作台风格，保留现有 Markdown 编辑、预览、图片及发布流程；不因视觉改版替换核心编辑能力。

## 5. 受控自定义

新增「外观与内容」，按分组表单编辑：

| 分组 | 字段与约束 |
| --- | --- |
| 站点身份 | 中英文名称（各最多 80 字）、简介（各最多 300 字），保留现有 Logo/Favicon 上传与恢复入口 |
| 首页内容 | 中英文小字（各最多 80 字）、主标题（各最多 120 字）、副标题（各最多 400 字）、作者名称（最多 80 字）、中英文介绍（各最多 600 字）、介绍显示开关 |
| 主题 | 强调色、纸色背景预设（暖纸/象牙/中性）、标题字体（衬线/无衬线）、默认模式（浅色/深色/跟随系统） |
| 文章展示 | 列表/卡片、封面开关、每页数量（6/9/12/18） |
| 导航 | 固定公开入口的中英文名称、显示开关和上下移动排序；首页始终可访问，隐藏不改变路由权限 |
| 页脚 | 中英文版权文案（各最多 200 字）、备案文字及链接、最多 8 个社交链接（名称最多 40 字、URL 最多 2048 字） |

主题设置使用受控取色与可读性检查；不合格的强调色拒绝保存并提供可用替代色，深色主题使用适配色，不能把任意输入直接拼进样式。

中文字段具有默认内容；英文留空时回退对应中文，不对站点配置触发 AI 翻译。图片继续复用现有上传管线，不引入远程脚本或任意图片协议。

访客已明确选择的主题优先于站点默认模式；仅未选择时采用站点默认值。

## 6. 编辑、预览与保存

- 文本与外观设置使用本地草稿；修改不会立即影响访客。
- 同页面提供复用前台组件的预览，支持桌面/移动宽度及浅/深主题，不发布草稿，也不向公共接口暴露草稿。
- 保存时后端整份校验并原子更新配置；失败保留用户输入并定位字段错误。
- 成功后刷新共享设置上下文，当前页面立即使用新配置；其他访客下次加载设置时读取新值，不承诺实时推送。
- 「取消修改」还原最后保存内容；离开未保存表单时提示。
- 「恢复默认外观」先确认，只重置主题和文章展示字段到草稿，点击保存后才生效；不删除文章、品牌内容、图片或 OAuth 设置。
- Logo/Favicon 保留独立上传与删除接口，操作立即生效，界面明确标注，与待保存的文本/主题草稿区分。

## 7. 技术设计与兼容

延续 React 19、TypeScript、Tailwind 4 和现有路由懒加载，不引入整套大型 UI 框架。

后端复用 Setting 模型，新增独立版本化文档 `site.presentation`，不覆盖其他设置键。配置规范化、默认值和校验集中到独立服务；拒绝未知字段和危险 URL 协议，社交链接仅接受 HTTP(S)，外链使用安全 rel 属性。

扩展公共设置接口，明确白名单返回品牌和展示字段，绝不返回 OAuth 密钥或 AI 配置。新增管理员读取/更新外观接口，沿用 protect 与 authorize('admin')；同步更新前端 services/api.ts。

SettingsContext 承载规范化展示配置，兼容原 logoPath/faviconPath/siteTitle 消费者。新配置不存在时回退旧站点标题与上传资源，并补齐 A 方案默认值；无需执行破坏性数据迁移。初次加载失败使用安全默认值，后续刷新失败保留已成功加载的配置并显示错误，不突然清空品牌资源。

组件边界：公共布局、工作台布局、设计基础组件、外观编辑表单、预览组件、配置数据访问相互分离。AdminPanel 只做与此次改版直接相关的模块拆分，避免单文件继续膨胀。

## 8. 验收与验证

- 前台所有现有路由、后台 13 个模块及新建/编辑文章都有一致的设计，不只改首页。
- 在 375px、768px、1440px 宽度验证布局，页面无意外横向溢出。
- 浅/深色、中/英文、长标题、无封面、空列表、加载与接口错误均可用。
- 外观保存后刷新页面仍然存在；非管理员不可修改；非法字段、颜色和 URL 被拒绝；公共响应不泄露秘密。
- 本地预览和取消不改变公共配置；恢复默认不清空品牌或业务数据。
- 回归登录/OAuth、管理员会话、文章编辑、评论、公告、友链、上传和后台设置。涉及真实发布、删除或修改生产配置的验证使用隔离数据，不直接操作生产内容。
- 为配置默认值、校验、权限、持久化和关键前端交互补充自动化测试；运行 frontend build/lint 并区分现有问题与本次新增问题。
- 浏览器实际检查前后台桌面/移动布局与控制台；无法使用真实服务验证的项目明确记录，不宣称已完成验证。
